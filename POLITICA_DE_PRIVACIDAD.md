## 3. Datos que Recopilamos

El Bot recopila la siguiente información necesaria para su funcionamiento:

### 3.1 Datos de Usuario
- ID de usuario de Discord
- Nombre de usuario de Discord
- Avatar del usuario
- Estado de administrador o permisos en el servidor

### 3.2 Datos del Servidor
- ID del servidor de Discord
- Nombre del servidor
- Configuración del Bot en el servidor
- Roles y permisos del servidor

### 3.3 Datos de Interacción
- Comandos utilizados
- Mensajes en los que se menciona el Bot
- Acciones realizadas a través del Bot (moderación, etc.)
- Timestamps de las interacciones

### 3.4 Datos de Registro (Logs)
- Registros de errores
- Registros de actividad del Bot
- Información técnica para depuración

## 4. Cómo Usamos tus Datos

Utilizamos los datos recopilados para:

- **Proporcionar funcionalidad:** Asegurar que el Bot funcione correctamente
- **Moderar el servidor:** Aplicar reglas de moderación y seguridad
- **Mejorar el servicio:** Analizar errores y mejorar el rendimiento del Bot
- **Cumplir con las políticas:** Cumplir con los Términos de Servicio de Discord
- **Seguridad:** Detectar y prevenir abuso, spam y actividades maliciosas
- **Estadísticas:** Recopilar datos anónimos sobre el uso del Bot

## 5. Base Legal

El tratamiento de tus datos se basa en:

- Tu consentimiento al usar el Bot
- La necesidad de cumplir con los Términos de Servicio

- El cumplimiento de obligaciones legales

## 6. Compartición de Datos

**No compartimos tus datos personales con terceros**, excepto en los siguientes casos:

- **Discord:** El Bot opera en Discord y debe cumplir con sus políticas
- **Cuando sea legalmente requerido:** Si una autoridad legal lo requiere
- **Protección de derechos:** Para proteger nuestros derechos o la seguridad de usuarios
- **Proveedores de servicios:** Solo si es absolutamente necesario para el funcionamiento

## 7. Retención de Datos

- Los datos se mantienen mientras el Bot esté activo en el servidor
- Cuando se retira el Bot, los datos se eliminan en un plazo de 30 días
- Los logs de errores se retienen durante máximo 90 días
- Puedes solicitar la eliminación de tus datos en cualquier momento

## 8. Seguridad de Datos

Implementamos medidas de seguridad para proteger tus datos:

- Encriptación cuando sea posible
- Acceso limitado a información sensible
- Monitoreo regular de seguridad
- Cumplimiento con las mejores prácticas de seguridad

**Nota:** Aunque nos esforzamos por proteger tus datos, ningún sistema es 100% seguro. No podemos garantizar seguridad absoluta.
